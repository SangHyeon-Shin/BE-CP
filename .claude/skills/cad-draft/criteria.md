# CAD 도면 작성 기준

cad-draft 스킬이 매 도면에 적용하는 기준이다. 각 절의 "검사" 항목은 QA 스크립트로 수치 검사한다.
사용자의 수정 요청에서 나온 일반 규칙은 맨 아래 `누적 기준`에 추가한다. 특정 도면의 좌표나 배치는 넣지 않는다.

## 1. 벽: 틈 없이 연결, 내부 채움

- 벽은 중심선과 두께로 정의하고, 모든 벽을 하나의 다각형으로 합쳐(union) 외곽선을 만든다. L·T·십자 접합부는 겹치거나 비지 않게 처리한다. 끝점 스냅 허용오차는 1 mm다.
- 개구부(문·창) 폭만큼 벽을 끊은 뒤의 다각형이 최종 벽체다.
- 벽체 내부는 닫힌 경계의 HATCH로 채운다. 패턴과 레이어는 샘플의 벽 해치를 따르고, 샘플에 없으면 SOLID를 쓴다.
- 벽 두께는 이미지의 치수·표기에서 읽는다. 없으면 가정값을 쓰고 `가정`으로 기록한다.
- 검사
  - 합친 벽 다각형의 개수가 예상값과 같다(개구부로 나뉜 경우 그 수만큼).
  - 벽과 벽 사이 1 mm 이상의 틈: 0개
  - 다른 벽에 닿지 않는 벽 끝(자유단)은 이미지에서도 자유단인 경우만 허용한다.
  - 해치 경계와 벽 다각형이 일치한다(면적 차 0.1% 이하).

## 2. 문·창문: 이미지 위치, 종류, 열림 방향

- 위치(어느 벽, 벽 시작점에서의 거리, 폭)는 치수로 정하고, 치수가 없으면 축척으로 잰다. 근거는 `evidence`에 남긴다.
- 문틀·창 블록은 샘플에서 가져와 삽입한다.
- 문 종류는 이미지 기호로 판별한다: 외여닫이, 양여닫이, 미닫이, 미서기, 접이, 현관문, 개구부(문 없음).
- 열림 방향은 두 가지를 읽는다.
  - 경첩 쪽: 벽의 start→end 방향 기준 좌/우
  - 열리는 쪽: 어느 방으로 열리는지
  
  이미지의 호(arc)와 문짝 선에서 읽고, 블록은 회전·대칭으로 맞춘다. 대칭한 뒤에는 실제 방향이 이미지와 같은지 다시 확인한다.
- 기호가 흐리거나 두 가지로 해석되면 방향을 확정하지 않고 `확인 필요`로 둔다.
- 검사
  - 모든 개구부가 벽 위에 있고, 개구부 폭과 블록 폭의 차가 1 mm 이하다.
  - 문의 열림 호가 벽 다각형과 겹치지 않는다. 겹치면 이미지를 다시 확인한다.
  - 문끼리 열림 범위가 충돌하면 보고만 한다. 이미지에 그렇게 그려져 있으면 고치지 않는다.

## 3. 가구·위생도기: 샘플 소스 우선, 크기 불변, 벽과 겹침 금지

- 샘플 CAD 블록을 우선 쓴다. 블록 정의는 수정하지 않고, 축척 1:1:1로 삽입하며, 회전·대칭만 허용한다.
- 위생도기(양변기, 세면기, 욕조, 샤워부스, 소변기, 주방 싱크)는 크기와 비율을 바꾸지 않는다. 공간이 부족해도 줄이지 말고 `확인 필요`로 보고한다.
- 위치와 방향은 이미지를 따른다. 벽에 붙는 도기(양변기 등판, 세면기, 욕조 긴 변)는 이미지에서 붙어 있는 벽 쪽에 둔다.
- 샘플에 해당 블록이 없으면 단순 기호를 별도 레이어에 그리고 `샘플 없음`으로 기록한다.
- 검사
  - 블록 형상(가능하면 실제 형상, 안 되면 바운딩 박스)과 벽 다각형의 교차 면적: 0
  - 블록끼리의 겹침: 0
  - 모든 블록 삽입 축척 = 1(대칭은 부호만 허용)

## 4. 치수: 이미지 숫자와 기준점, 실제 크기

- 이미지 숫자와 그 치수선이 가리키는 기준점(벽 중심선·외곽·내측 마감)을 확인하고, 도면에서도 같은 기준점 사이에 치수를 건다.
- 형상은 그 숫자대로 실제 크기(mm)로 그린다. 치수 엔티티는 형상에서 측정한 값을 그대로 표시한다.
- 치수 텍스트 덮어쓰기(text override)를 쓰지 않는다. 숫자만 바꿔서 맞춘 것처럼 보이게 하지 않는다.
- 치수 스타일은 샘플 DIMSTYLE을 그대로 쓴다(글자 높이, 화살표, 정밀도, 단위).
- 이미지 숫자끼리 모순되면(예: 연속 치수 합 ≠ 전체) 형상을 억지로 맞추지 않는다. 모순된 숫자를 `확인 필요`로 표시한다.
- 검사
  - 모든 치수 엔티티의 측정값과 이미지 숫자의 차: 0.5 mm 이하
  - 연속 치수의 합 = 전체 치수
  - 텍스트를 덮어쓴 치수: 0개
  - 픽셀 축척 교차 확인에서 치수 간 축척 편차가 2%를 넘으면 해당 치수를 보고한다.

## 5. 방 이름, 확인 필요 표시

- 방 이름은 이미지 표기 그대로 쓴다. 샘플 텍스트 스타일로, 방 다각형 안의 시각적 중심(polylabel)에 넣는다.
- 이름을 읽을 수 없으면 `확인 필요`로 둔다.
- `확인 필요` 표시
  - 레이어 `확인필요`(빨강)에 `확인 필요: <사유>` 텍스트와 위치 표시 원을 넣는다.
  - 도면의 표시 개수와 `report.md` 목록의 개수가 같아야 한다.
- 면적을 적을 때는 기준(벽 중심선 또는 내측)을 함께 적는다.

## 6. 출력

- DWG 변환기가 있으면 DWG도 만들고 다시 읽어 검증한다. 없으면 DXF만 제공하고 이유를 적는다.
- DXF 버전과 단위(`$INSUNITS`)는 샘플을 따른다. 한글 문자열이 깨지지 않는지 다시 읽어 확인한다.
