# 시연 시나리오: 실제 업무로 효과 확인하기

목표: 담당자가 **이미 답을 아는 실제 업무**로 AI를 시험해, 맞는지와 얼마나 빠른지를 직접 확인한다. 전체 약 40분.

> **Codex·Claude에게:** 사용자가 "시연 N번 진행해줘"라고 하면 이 문서의 해당 시연을 진행한다.
> - 시작 전에 사용할 파일을 확인한다.
> - 원본이 아닌 `데모` 폴더의 사본만 쓴다.
> - 끝나면 결과를 점수표 형식으로 정리한다.
> - 확실하지 않은 값은 "확인 필요"로 표시한다.

## 1. 준비(시연 전날, 10분)

| 준비물 | 내용 | 왜 |
|---|---|---|
| **완료된 프로젝트 1건** | 담당자가 이미 계산을 끝낸 프로젝트 | AI 결과를 정답과 비교할 수 있다 |
| DWG 사본 | 평면도(실 경계 폴리라인이나 해치가 있으면 좋음) | 면적·외피 수량 시연 |
| 창호일람표 PDF | 같은 프로젝트 | 창호 수량 시연 |
| 정답 자료 | 그 프로젝트의 면적표, ECO2 입력값 또는 에너지절약계획서 | 대조용. **AI에게는 먼저 보여주지 않는다** |
| 외벽 단면 1개 | 재료·두께가 적힌 단면 상세 | 결로 시연 |
| HWP 1건 | 인증기관 보완요청서나 공문 | 서류 시연 |

- 모든 파일은 **사본**을 `Documents\도면\데모` 같은 폴더에 둔다. AutoCAD 연결 때 지정한 `ALLOWED_PATHS` 안이어야 한다.
- 담당자에게 각 작업을 **평소에 몇 분 걸리는지** 미리 적어 달라고 한다(점수표의 "평소 시간").
- 시연 직전: AutoCAD에서 DWG 사본을 열어 두고, Codex를 `BE-CP` 폴더에서 연다.

## 2. 진행 순서

| 순서 | 시연 | 시간 | 보여줄 것 |
|---|---|---|---|
| 1 | 법규 즉답 | 3분 | 조문 번호와 원문으로 답한다 |
| 2 | 면적·외피 수량 | 12분 | **담당자가 계산한 값과 일치하는지**(핵심) |
| 3 | 창호일람표 정리 | 7분 | PDF 표 → 엑셀, ECO2 입력 준비 |
| 4 | 결로 검토 | 7분 | 단면 층별 온도와 이슬점 위치 |
| 5 | AutoCAD 직접 조작 | 5분 | 말로 시키면 도면에 그려진다. Ctrl+Z로 되돌려진다 |
| 6 | HWP 서류 | 6분 | 보완요청서 → 항목별 답변표 초안 |
| 7(추가) | ECO2 입력 검토 | 8분 | 완료한 ECO2·ECO2-OD 파일의 입력값을 도면·기준과 대조 |

쉬운 것(1)으로 시작하고, 정답 대조(2)로 신뢰를 얻은 뒤, 눈에 보이는 것(5)과 서류(6)로 마무리한다.

## 3. 시연별 프롬프트

### 시연 1. 법규 즉답(3분)
담당자가 답을 아는 질문을 직접 고르게 한다. 예:
```
건축물의 에너지절약설계기준에서 중부2지역 거실 외벽(외기 직접)의 열관류율 기준을 찾아 줘.
고시 번호, 시행일, 해당 별표, 원문을 같이 보여 줘.
```
- 확인: 담당자가 아는 값과 같은지, 출처(별표·시행일)가 맞는지.

### 시연 2. 면적·외피 수량(12분, 핵심)
```
데모 폴더의 [파일명].dwg 사본으로 다음을 표로 정리해 줘.
1. 실별 면적표(실 이름, 면적 m²)와 층 합계
2. 방위별(동·서·남·북) 외벽 면적과 창 면적
도면을 직접 수정하지 말고 읽기만 해. 실 경계가 불분명한 곳은 추측하지 말고 "확인 필요"로 표시해 줘.
```
- 확인: 담당자의 면적표·ECO2 입력값과 **항목별로 대조**한다. 차이가 나면 이유(실 경계 기준, 벽 중심선 vs 안목)를 AI에게 설명하게 한다.
- 핵심 메시지: "맞는 것은 빨리 끝나고, 다른 곳은 AI가 왜 다른지 짚어 준다."

### 시연 3. 창호일람표 정리(7분)
```
$schedule-extractor
데모 폴더의 창호일람표 PDF를 엑셀(CSV)로 정리해 줘. 창호 기호, 크기(W×H), 수량, 면적, 유리·프레임 사양을 열로 만들고,
읽기 어려운 칸은 "확인 필요"로 표시해 줘.
```
- 확인: 몇 줄을 원본과 대조한다. 합계 면적을 시연 2의 창 면적과 비교한다.

### 시연 4. 결로 검토(7분)
설계 조건(실내 온습도, 외기 온도)은 담당자가 평소 쓰는 값을 직접 말하게 한다.
```
$condensation-check
이 외벽 단면의 결로 위험을 검토해 줘. 층 구성(바깥→안): [재료와 두께를 순서대로].
재료 열전도율은 [평소 쓰는 값 또는 제조사 자료, 재료별로] 쓰고,
실내 [ ]℃ [ ]%, 외기 [ ]℃ 조건으로 층별 온도와 이슬점을 표로 보여 줘. 단위는 W/m²K로.
```
- 확인: 열관류율 계산값을 담당자 계산과 비교한다. 이슬점이 생기는 층이 상식과 맞는지 본다.

### 시연 5. AutoCAD 직접 조작(5분)
```
AutoCAD에 열린 도면(사본)에 "AI-시연" 레이어를 새로 만들고, 그 레이어에 6000×4000 mm 사각형과
가운데에 "AI 시연 거실 24.0㎡" 문자를 넣어 줘. 다른 레이어는 건드리지 마.
```
- 보여줄 것: 도면에 바로 그려지는 것. **Ctrl+Z 한 번에 전부 되돌려지는 것**(안전성).
- 이어서 실용 예: "이 도면의 레이어 목록과 각 레이어의 객체 수를 표로 보여 줘."

### 시연 6. HWP 서류(6분)
```
$plan-check-response-builder
데모 폴더의 [보완요청서].hwp를 읽고, 요구사항을 항목별 표로 정리한 뒤 항목마다 답변 초안과
필요한 증빙 서류를 적어 줘. 모르는 내용은 비워 두고 "확인 필요"라고 써 줘.
```
- 확인: 빠진 요구사항이 없는지 담당자가 원본과 비교한다.

### 시연 7(추가). ECO2 입력 검토(8분)
완료한 프로젝트의 ECO2-OD(.ECL2) 또는 ECO2(.eco) 사본을 데모 폴더에 둔다.
```
$eco2
데모 폴더의 [파일명] 사본의 입력값을 검토해 줘. 외피(면적·방위·열관류율), 재료층, 냉난방·조명 설비를 표로 정리하고,
시연 2에서 구한 도면 면적과 창호일람표, 에너지절약설계기준의 열관류율 기준과 대조해 차이를 표로 보여 줘.
원본은 바꾸지 마.
```
- 확인: 담당자가 아는 입력값과 같은지, AI가 짚은 차이가 실제 입력 실수인지 본다.

## 5. 시연할 때 지킬 것

- **원본 파일은 쓰지 않는다.** 사본만 쓴다.
- AI가 틀리면 숨기지 않는다. "틀린 곳을 사람이 확인해서 잡는 흐름"도 보여줄 내용이다.
- Codex가 명령 허락을 물으면 담당자가 직접 승인하게 한다. 통제권이 사람에게 있다는 것을 보여 준다.
- 잘 안 된 시연은 "고칠 점"에 적는다. 다음에 스킬이나 지침(`AGENTS.md`)을 고칠 근거가 된다.

## 6. 문제가 생기면

| 증상 | 조치 |
|---|---|
| 면적이 크게 다름 | 실 경계 기준(벽 중심선/안목)을 AI에게 알려 주고 다시 계산 |
| DWG를 못 읽음 | AutoCAD에서 DXF로 저장한 사본을 쓰거나, AutoCAD 연결로 직접 읽게 함 |
| AutoCAD 응답 없음 | AutoCAD에 열린 대화상자를 닫고 Esc, 다시 요청 |
| 법령 조회 실패 | `python tools/check_setup.py`로 연결 확인 |
| HWP를 못 읽음 | 한글에서 PDF로 저장한 사본으로 진행 |
